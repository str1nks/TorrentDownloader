# TorrentDownloader

**Простой торрент-загрузчик для Windows в стиле Windows 11 (Fluent / WinUI)**

Вставьте magnet-ссылку или выберите `.torrent` файл, укажите папку и качайте. Без рекламы, лишних вкладок и настроек.

## Возможности

- **Два способа добавить загрузку**: magnet-ссылка или `.torrent` файл.
- **Выбор папки сохранения**. По умолчанию это папка «Загрузки» пользователя.
- **Живая статистика**: прогресс-бар и проценты, скорость, число пиров, скачанный и общий объём, оставшееся время.
- **Пауза, продолжение и отмена** загрузки.
- **Понятные статусы**: получение метаданных, проверка файлов, скачивание, выделение места, завершено.
- **Уведомления внизу окна** (InfoBar): ошибки, начало и завершение загрузки.
- **Оформление под Windows 11**: карточки, акцентные кнопки, Fluent-палитра. Светлая или тёмная тема подстраивается под систему автоматически.
- Свой значок приложения на панели задач и в заголовке окна.

Загрузка идёт на движке [libtorrent](https://www.libtorrent.org/), интерфейс построен на [customtkinter](https://github.com/TomSchimansky/CustomTkinter).

## Установка и запуск

### Из исходников

```bash
pip install -r requirements.txt
python torrent_downloader.py
```

Зависимости: `customtkinter` и `libtorrent`.

### Готовый .exe

Скачайте `TorrentDownloader.exe` из раздела [Releases](../../releases) и запустите. Python устанавливать не нужно.

## Как пользоваться

1. Вставьте **magnet-ссылку** в поле «Источник» или нажмите **«Обзор…»** и выберите `.torrent` файл.
2. При необходимости нажмите **«Изменить»** и выберите другую папку сохранения.
3. Нажмите **«Начать загрузку»**.
4. Следите за прогрессом. При необходимости используйте **«Пауза»** / **«Продолжить»** или **«Отменить»**.

Для magnet-ссылок сначала выполняется получение метаданных, и только потом показываются имя и размер.

## Сборка .exe

В репозитории есть готовый файл сборки `TorrentDownloader.spec`:

```bash
pip install pyinstaller customtkinter libtorrent
pyinstaller TorrentDownloader.spec
```

Результат: `dist\TorrentDownloader.exe`. Это один файл без консольного окна, со значком `app.ico`. Ресурсы `customtkinter` и библиотеки `libtorrent` собираются в него автоматически.

Если установлен [UPX](https://upx.github.io/), PyInstaller дополнительно сожмёт файл. Если нет, сборка пройдёт без сжатия.

## Технические детали

- Для входящих соединений используется порт **6881**. При первом запуске Windows может показать запрос брандмауэра: разрешите доступ, чтобы количество пиров не страдало.
- Обновление интерфейса происходит дважды в секунду в главном потоке.
- Для старых версий `libtorrent` предусмотрены запасные вызовы (`listen_on`, разбор magnet-ссылок).

## Ограничения

- Одновременно скачивается один торрент.
- Выбора отдельных файлов внутри торрента нет, скачивается всё содержимое.
- После завершения загрузки раздача останавливается, а состояние не сохраняется между перезапусками программы.

## Законное использование

Программа предназначена для загрузки легального контента: дистрибутивов, открытых данных, собственных и свободно распространяемых файлов. Ответственность за загружаемые материалы лежит на пользователе.
